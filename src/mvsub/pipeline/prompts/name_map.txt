# 固定人名对照表（可选）
#
# 为什么需要：
#   1) 人名原本靠模型每次通读原文自己生成"全局人物关系"，同一人物在不同片里写法不一；
#      模型认不出来就原样留日文，整句因此带假名，被验收闸门判成漏译。
#   2) 语音识别会听错人名（相近读音的假名极易混淆），模型拿到错字只好留原文。
#
# 本表优先于模型自生成的人物关系：翻译前注入 prompt，翻译后按表做一次"残留日文名归一"。
# 只做表内命中的替换 —— 表里没有的日文一律不动，不会擅自改动原文。
#
# 格式：日文<TAB>中文<TAB>类别<TAB>说明     （# 开头为注释，类别可留空）
#   类别：actress=演员/人物名   fix=语音识别误听纠正   role=片中角色   call=称呼
#   call 类别支持后缀规则：写 `〜ちゃん` 表示"名字 + ちゃん"统一译成"名字 + 酱"。
#
# 用法：
#   1. 复制本文件为同目录的 name_map.txt（本模板本身留在这里当格式说明）；
#   2. 一行一个人名，用 TAB 分隔，不要用空格；
#   3. 留空也是合法状态：表为空即等于不启用该功能。
#
# 示例（取消注释后按需改成你自己片子里的名字）：
# 山田太郎	山田太郎	role
# さくら	樱	fix	识别常把 さくら 听成 ざくら
# 〜ちゃん	〜酱	call
